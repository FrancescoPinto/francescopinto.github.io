# Academic portfolio

A dependency-free, responsive academic website designed for GitHub Pages.

## Personalise it

The site is populated from the supplied CV. The short bio, themes, and papers are kept together in `site.js`; update that file when your record changes. The excluded publication is not referenced or included.

## Publish with GitHub Pages

1. Create a new GitHub repository and upload the contents of this folder (not the folder itself).
2. On GitHub, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, then select `main` and `/(root)`.
4. Save. GitHub will provide the public address in the same panel.

For a project repository called `portfolio`, the URL is normally `https://USERNAME.github.io/portfolio/`.
